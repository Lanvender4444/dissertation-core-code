# 补充实验 supp_20261101（论文 v1.0）

按 `docs/thesis/SUPPLEMENTARY_EXPERIMENTS_GUIDE_20261101.md` 执行。全部实验只读冻结数据：不跑 YOLO、不改 XML、不改任何已有实验目录。脚本在 `scripts/supp/`。

## 复现性前提

- `extract/run01/frames/*.json`：1655 帧紧凑快照（检测池原始/校正框、射线、crop 窗口、各相机 GT、F5-P 成员、F5-R root+路径）。抽取时逐帧与冻结计数比对，**0 帧不一致**。
- `supp_lib.py` 重新实现论文匹配协议，复现全部冻结总数：A 10366/1044，F5-P 10606/1120，仅修复 10737/986，F5-R 11143/1124，原始池 14260 / 校正后 14464。
- E3 用冻结特征库重放冻结 residual 模型，184 帧路径/分数/计数完全一致；未消融臂从零重拟合后精确复现 F5-R（同一 τ=0.5559…）。

## 结果目录

| 目录 | 内容 | 关键结果 |
|---|---|---|
| `e1_e6_error_analysis/` | E1 融合前检测行为；E6 按尺寸/类别/可见相机拆分 | 小目标(25–50px)单相机召回仅 10–23%；多视角可见目标中 45% 一个视角都没检出；鱼眼漏检前向已检出目标 47.5%；crop 输入只挡住 0.95% GT（召回上限≈99%）；F5-R 对 >100px 目标保留原始池召回的 90%，25–50px 仅 58% |
| `e2_simple_baselines/` | B1 置信度阈值 / B2 射线 NMS / B3 ≥2 视角投票 / B3′；仅 dev 段选参 | B2 召回相近(46.4%)但精度只有 62.6%（F5-R 90.84%）；投票法精度 85% 但召回只有 22%；B2 在 P≥90% 时最大召回 3.3% |
| `e3_feature_ablation/<arm>/` | residual 头按证据类型消融并重拟合 | 去掉跨视角竞争证据 −1.01 召回点（最大）；去掉射线几何 −0.29；去掉外观 −0.27；相机 ID 列从未被树使用（结果完全相同）；仅检测器特征 −1.62 |
| `e3b_fisheye_output/` | 输出层去掉 Cam1/Cam5 成员 | 五目召回 44.85%→28.26%，鱼眼贡献约 37% 的 TP；纯鱼眼对象精度 91.5% |
| `e4_association/` | 用标注 instanceId 做成对关联评估 | F5-R 成对关联精度 98.1%、召回 96.6%、组纯度 97.5%；B2 只有 83.5%/71.9%/76.5%；针孔–鱼眼配对 366 对、0 错 |
| `e4_identity_audit/` | 123 个多视角组盲评（crop 图 `sheets/`、`labels.csv`） | 随机层 47/47 可判定为同一物体；标注“不一致”的 33 组中 25 组实际同一物体、1 组错、7 组不确定。**标签由 AI 助手看图给出，请在 `labels.csv` 的 candidate_label 列自己复核** |
| `e5_ap/` | 单相机 COCO 式 AP；融合输出 group AP | 单相机 AP50 0.23–0.30（严格类别）；F5-R group AP50 0.431（F5-P 0.411）；B2 AP50 0.443 略高，因为它把低精度长尾也算进去——在 P≥90% 时 F5-R 召回比 B2 高 41 点 |
| `figures/` | 论文新增图（PDF+PNG） | |

`e3_feature_ablation/training_samples.npz`（282MB 缓存）未拷回，运行 `python3 scripts/supp/e3_feature_ablation.py train` 会从冻结特征库重新生成。
