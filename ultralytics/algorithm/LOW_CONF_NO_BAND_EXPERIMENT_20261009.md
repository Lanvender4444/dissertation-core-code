# 降低YOLO阈值：无BAND单Cam、三目融合、鱼眼辅助的全域实验

日期：2026-10-09。状态：完整跑完1,655帧、五相机8,275张图，36个预先固定的实验配置。历史报告没有覆盖；默认可视化入口没有修改。

机器可读结果：`ultralytics/algorithm/evaluation_reports/low_conf_no_band_results_20261009.json`。其中包含逐帧计数、全部配置、分段结果、配对区块bootstrap、源代码快照、固定评分模型和输入校验信息。

## 1. 先说结论

- **降低YOLO阈值确实提高召回，但没有使同一个系统的Precision与Recall同时提高。** 从0.10到0.05，三目融合在前向GT下P：93.25%→88.85%，R：36.82%→39.09%。
- **单Cam直接降低阈值，误报增长很大。** 本轮统一输入门槛后，0.01时三个单Cam的前向Recall约51%—53%，但Precision只有约15%。
- **同一低阈值下，加入鱼眼验证与侧向补盲有效。** 0.05、五目GT下，三目融合P/R为88.84%/21.20%，五目补盲τ=0.75为93.37%/28.91%，提高4.53/7.71个百分点。
- **只验证前向对象，不输出侧向独有对象，并没有提高召回。** 0.05时，这个辅助-only版本P/R为92.77%/19.79%；它提高精度，但漏掉更多对象。
- **不要把降低门槛称为新算法突破。** 五目τ=0.75从YOLO 0.10降到0.05，只多150个TP，却多144个FP；R仅提高0.60个百分点，P下降1.68个百分点。0.01也没有解决低召回根因。

本报告的“精度”指Precision，不是有TN的分类Accuracy。FP也可能是重复输出、框定位偏差或类别不兼容，不能全部解释成“根本不存在的物体”。

## 2. 实验到底改了什么

| 项目 | 本轮设定 |
| --- | --- |
| 检测器 | 固定YOLO11n，原权重SHA-256不变，没有训练或微调YOLO |
| 输入 | 原始2464×2056图像，YOLO `imgsz=960`，不使用BAND、不裁局部增强 |
| YOLO候选阈值θ | 0.10、0.05、0.03、0.01 |

| NMS | 原生class-aware NMS，IoU=0.7，max_det=300；之后保留类别0/1/2/3/5/7 |
| 单Cam | 三个相机都使用当前θ，不再暗中套用旧0.15/0.20/0.25门槛；原自车过滤不变 |
| 三目主实验 | 当前冻结深度证据评分τ=0.5＋E1，多目关联规则不变 |
| 三目额外控制 | 仅将同一个融合评分τ放宽到0.3；明确不是“只改YOLO阈值” |
| 鱼眼关联 | 原`shared_component`，gate=0.45、margin=0.02，固定物体状态模型 |
| 五目评分 | 复用2026-10-08的`shared`评分模型，不重新拟合，分别用τ=0.75/0.85 |
| 时间/相机/GT范围 | 同一批1,655帧，Cam1/2/3/4/5；标定、类别兼容和GT规则不变 |

**三个阈值不能混为一谈：** θ是YOLO候选门槛；三目τ是前向对象保留门槛；五目τ是后处理评分门槛。例如“YOLO 0.05＋五目τ=0.85”并不是YOLO置信度0.85。

三目主实验仍使用当前冻结参数（`BAND_d_E1.json`那份固定权重）。文件名里有BAND不代表本轮输入带BAND。没有切换到历史“原960评分”，没有替换主算法，也没有新增Cam3单独去重方案。

鱼眼两种输出逻辑：

1. `fish_aux_only075`：以已经通过三目核验的对象为锚点，关联Cam1/5，重新评分，但**不新建侧向独有对象**，也不救回之前被三目评分拒绝的对象。
2. `fish_full075/085`：上述关联之后，允许侧向独有对象通过固定评分进入场景；可能与既有对象重复但身份未定的候选进入诊断unknown，不直接当作假目标。

鱼眼候选空间由前向框射线、尺寸先验和可用的射线三角化生成：12个对数间隔距离样本，另加三角化距离附近样本，并组合朝向、尺寸尺度和受限可见中心偏移。它没有把SGBM点直接当作精确侧向投影坐标。共享状态竞争判据是**有限假设集内**的判断，不是连续空间或整套五目真实身份的保证。

## 8. 为什么降低阈值后，最终Recall仍然不高

### 8.1 候选确实增加了，但不等于可直接输出

把五相机原生检测框全部作为单框候选，暂不做自车过滤、融合或后处理评分，检查这批框在五目GT下能达到的最大一对一匹配数量：

| YOLO θ | 原生目标类别框总数 | 可匹配TP | 尚无法匹配FN | 候选覆盖Recall |
| ---: | ---: | ---: | ---: | ---: |
| 0.10 | 36976 | 9793 | 15052 | 39.42% |
| 0.05 | 60816 | 10907 | 13938 | 43.90% |
| 0.03 | 89145 | 11768 | 13077 | 47.37% |
| 0.01 | 205113 | 13375 | 11470 | 53.83% |

这不是可部署方法，也不是YOLO的固有召回上限；是**当前模型、960分辨率、这批NMS后的原生框、这套类别/IoU/GT规则**下的候选覆盖。多视图原生框并列会产生大量同物重复，因此不能把该池的Precision当成单Cam模型精度。

门槛降低不会放大远处物体，也不会自动修正偏框或错误类别。原图25px高的目标缩到960输入大约只剩9.7px；小目标、鱼眼畸变、遮挡与定位误差仍可能让框达不到IoU标准。这些是机制解释，并非本轮已经逐项消融证明的FN原因。

### 8.2 后处理仍然很严格

| YOLO θ | 三目评分前对象候选 | 三目保留对象 | 侧向预处理后候选 | 接受的鱼眼关联 | 五目τ0.75输出对象 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.10 | 12844 | 5344 | 7867 | 174 | 7413 |
| 0.05 | 22458 | 5973 | 12292 | 178 | 7711 |
| 0.03 | 34000 | 6319 | 17667 | 164 | 7850 |
| 0.01 | 80413 | 6778 | 39576 | 142 | 8058 |

本表是流程对象数量，不等于TP＋FP，因为只命中小GT的部分输出在评价时被忽略。0.01下，五目评分移除32,837个候选对象；另有5,317个可能重复但身份未确定的侧向候选保留在unknown诊断中，而不是认定它们不存在。

原生框总数增长约5.55倍，但五目τ0.75的TP仅由7,033增到7,314。**输入不足有所缓解，已有核验/拒绝/评分逻辑又限制了这些新增弱框进入最终输出。**

更直接的证据：0.01时三目保留6,778个对象，其中2,599个含低于0.10的成员，但全部成员都低于0.10的对象仅12个。五目τ0.75保留8,058个对象，其中1,653个含低置信成员，全部成员均低于0.10的对象只有1个。0.05/0.03五目τ0.75没有任何“全成员低于0.10”的保留对象。

**这不是隐藏的旧YOLO阈值。低框确实参与了关联，但当前固定评分几乎仍要求至少一条较强观测。** 它更容易补足一个原本已有高置信观测的对象，而不是确认一个所有视角都很弱的新对象。本轮没有针对低阈值分布重新校准评分。

### 8.3 为什么Precision下降：一个简单推导

设原结果为TP=T、FP=F，降低阈值后净增加t个TP、f个FP，并且t、f≥0。则：

\[
P' = \frac{T+t}{T+F+t+f},\qquad
P'>P\iff\frac{t}{t+f}>\frac{T}{T+F}.
\]

也就是说，新增结果的正确比例必须比原结果还高，才能让整体Precision继续上升。

三目0.10→0.05净增加305 TP、302 FP，增量正确比例只有50.25%，低于原来的93.25%，所以Precision下降。五目τ0.75净增加150 TP、144 FP，增量比例约51.02%，也低于原95.05%。仅放宽YOLO门槛并没有提供让新增弱框更加可靠的独立证据。

另一个机制风险是：低阈值增加跨相机候选组合，可能发生偶然几何一致、竞争抢占和重新分组。融合输出集合不像裸单框候选那样必然嵌套，所以不能从“原生候选TP单调增加”直接推断融合Recall必然单调增加。本轮四个点的Recall上升，是实际结果，不是普适定理。

关联身份诊断仍有局限：本轮用共同0.01检测池与XML做GT对齐；它只是标注代理，重叠GT歧义和未对齐链接不能算作已人工证明的错配。三目已知链接代理错误率从约0.40%增到0.68%，五目τ0.75从约0.34%增到0.58%。侧向已知链接没有观察到代理错误，不代表所有侧向链接都正确；仍有未解和歧义链接，XML全局ID语义也未独立核实。

## 12. 本轮之后的判断

0.05可作为温和的召回取舍实验点，但不是已经证明优于0.10的最终默认配置；0.01不适合仅凭Recall升高直接采用。当前五目τ0.75曲线中0.01的F1最高（44.48%），但它的Precision低于0.10，且没有实时速度验证。

如果继续优化，重点应是**如何用独立跨视角证据确认低置信对象，同时避免低质量成员污染已有可信组**，并且区分前向对象验证与侧向独有目标补盲。若重新校准低阈值评分，必须另做开发/评价分离的实验，不能和本轮“固定评分，只降低YOLO门槛”的主结果混称。
